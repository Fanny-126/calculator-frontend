# Frontend Code Style

## 1. Overview

This document defines the coding style and development conventions used in the calculator frontend project.

The project follows common web development practices and refers to the Google JavaScript Style Guide and Google HTML/CSS Style Guide.

## 2. HTML Style

### 2.1 HTML5

Use the standard HTML5 document structure.

Example:

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Calculator</title>
</head>
<body>
    ...
</body>
</html>
