# Calculator Frontend

## 1. Project Overview

This project is the front-end part of a front-end and back-end separated calculator system.

The front end provides the user interface for entering mathematical expressions, displaying calculation results, viewing calculation history, and deleting history records.

The actual expression calculation is performed by the back-end service through HTTP API requests.

## 2. Features

The front-end application provides the following features:

- Enter mathematical expressions.
- Send calculation requests to the back-end API.
- Display calculation results.
- Display calculation errors.
- Retrieve calculation history from the back end.
- Delete individual history records.
- Refresh the calculation history.
- Support keyboard Enter to submit an expression.
- Connect to the deployed back-end service.

## 3. Technology Stack

- HTML5
- CSS3
- JavaScript
- Fetch API
- GitHub Pages
